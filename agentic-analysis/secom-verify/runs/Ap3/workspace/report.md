# 반도체 공정 불량 원인 탐색 보고서

## 결론

`sensor_251`의 **낮은 측정값**은 불량과 연관된 가장 유력한 *우선 점검 후보*이다. 다만 이 신호는 다중검정 보정의 엄격한 기준을 충족하지 못하고 시간 구간별 크기도 작아, 이 데이터만으로 원인 센서라고 확정할 수는 없다. 따라서 결과 파일에는 낮은 신뢰도(`low`) 후보 하나만 넣었으며, 고신뢰도 원인은 발견하지 못했다.

`sensor_306`도 단변량에서는 비슷한 방향의 신호를 보였지만 `sensor_251`과 강하게 같이 움직였다(Spearman 상관 0.713). 두 값을 함께 넣어 시간 보정하면 `sensor_306`의 독립 효과는 유의하지 않았다(p=0.191). 따라서 별도의 원인 후보로 중복 보고하지 않았다.

## 데이터 확인

- 웨이퍼: 1,567장, 센서: 590개
- 양품(`-1`): 1,463장, 불량(`1`): 104장 (불량률 6.64%)
- 측정 기간: 2008-07-19 ~ 2008-10-17
- 센서마다 결측이 있으며, 일부 센서는 관측된 행 수가 적었다. 결측 자체도 불량과 연관되는지 별도로 검사했다.

## 분석 방법

1. 각 센서에 대해 양품·불량의 분포를 Mann--Whitney 검정으로 비교하고, 효과 크기는 Cliff's delta로 계산했다. 590개를 동시에 살펴보므로 Benjamini--Hochberg FDR 보정을 적용했다.
2. 결측 여부와 불량의 관계는 Fisher 정확 검정으로 확인했다.
3. 측정 시각에 따른 설비/레시피 변화가 가짜 상관을 만들 수 있으므로, 관측치가 1,400개 이상인 422개 센서에 대해 시간순 10개 구간을 고정효과로 넣은 로지스틱 회귀를 추가로 수행했다. 센서는 표준편차 1 단위로 표준화했다.
4. 후보의 시간적 일관성은 시간순 5개 구간에서 효과 방향과 AUC로 점검했다. 또한 결측 중앙값 대치·표준화·L2 로지스틱 회귀로 전체 590개 센서의 8겹 층화 교차검증 성능을 확인했다.

## 주요 결과

### 전체 탐색 및 결측

- 원시 단변량 p값이 가장 낮은 것은 `sensor_298` (p=0.00109)였지만, FDR q=0.265로 유의하지 않았다. 상위 신호들이 590개 동시 검정 후 남지 않았으므로, 원시 p값 순위만으로 원인을 선언하지 않았다.
- `sensor_251`의 원시 단변량 p값은 0.00292였고, 전체 590개 보정 q값은 0.287이었다.
- 결측 여부의 연관성도 FDR 보정 후 유의한 센서가 없었다. 즉 특정 센서의 미측정 자체가 불량을 설명한다는 근거는 발견하지 못했다.
- 전체 센서를 모두 사용한 8겹 교차검증의 ROC-AUC는 0.525, 평균정밀도(AP)는 0.0747이었다(기준 불량률 0.0664). 이처럼 일반화 예측력이 낮은 점도 강한 단일 원인이나 안정적인 원인 조합이 없다는 판단을 뒷받침한다.

### `sensor_251` — 낮은 신뢰도의 우선 점검 후보

| 항목 | 값 |
| --- | ---: |
| 양품 평균 / 중앙값 | 355.31 / 353.93 |
| 불량 평균 / 중앙값 | 353.10 / 352.24 |
| 불량 판별 단변량 AUC (낮을수록 불량) | 0.587 |
| 시간 10구간 보정 계수 | -0.423 (표준편차 1 단위) |
| 시간 보정 p값 / 422개 FDR q값 | 0.000146 / 0.0615 |
| 시간 5구간의 효과 방향 | 5개 구간 모두 음수 |

시간을 보정한 단독 모형에서 측정값이 표준편차 1만큼 증가할 때 불량 오즈비는 약 0.655였다. 즉 값이 낮은 웨이퍼 쪽에서 불량이 조금 더 많았다. 다만 q=0.0615로 통상적인 0.05 문턱을 넘었고, 5개 시간 구간 중 뚜렷한 개별 유의성은 한 구간에서만 나타났다. 따라서 공정 엔지니어링 관점에서는 해당 센서가 대표하는 공정 조건과 장비 로그를 먼저 점검할 후보이지만, 원인 판정이나 한계값 설정에는 추가 실험/독립 기간 데이터가 필요하다.

### 함께 보인 신호의 배제

`sensor_306`은 시간 보정 단독 p=0.000525였으나 422개 FDR q=0.111로 보정 기준을 통과하지 못했다. `sensor_251`과 함께 모형에 넣으면 계수는 -0.200, p=0.191로 약해졌다. 두 값의 공선성 때문에 동일 공정 상태를 중복 반영한 관측 신호일 가능성이 높아, `sensor_251`의 독립적인 보조 근거 또는 공정 추적용 참고값으로만 취급하는 것이 적절하다.

## 권고

1. 다음 생산 기간에서 `sensor_251`의 낮은 값과 불량의 관계를 사전 등록된 기준으로 재검증한다.
2. `sensor_251`과 `sensor_306`이 연결된 공정 단계·장비·레시피를 함께 확인하되, 두 센서를 독립 고장 원인으로 해석하지 않는다.
3. 재현될 때까지는 자동 선별 임계값을 적용하지 말고, 이상 웨이퍼의 공정 이력 점검 알림 용도로만 사용한다.
