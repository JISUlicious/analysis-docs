# 반도체 공정 센서–불량 연관 분석 보고서

## 결론

이번 데이터에서는 불량의 원인으로 의심할 만큼 통계적으로 검증된 센서가 발견되지 않았다. 따라서 특정 센서를 불량 원인 또는 유의한 연관 후보로 보고하지 않는다. 이는 센서가 불량에 전혀 영향이 없음을 증명하는 결과라기보다, 현재 표본에서 590개 센서를 동시에 비교하고 시간 효과를 고려한 뒤에도 재현성 있는 신호를 확인하지 못했다는 뜻이다.

## 데이터 개요

| 항목 | 값 |
| --- | ---: |
| 웨이퍼 수 | 1,567 |
| 양품 (`label=-1`) | 1,463 |
| 불량 (`label=1`) | 104 |
| 불량률 | 6.64% |
| 센서 열 수 | 590 |
| 측정 기간 | 2008-07-19 11:55 ~ 2008-10-17 06:07 |

센서 중 116개는 상수였고, 사실상 상수인 6개 및 결측 비율이 50%를 넘는 28개를 포함한 품질 문제를 고려해 검정 가능한 센서는 468개였다. 결측치는 각 센서의 가용 관측치만 사용했다.

## 분석 과정

- 각 검정 가능 센서에 대해 양품과 불량의 분포 차이를 양측 Mann–Whitney U 검정으로 평가했다.
- 468개 동시 검정에서 우연한 발견을 제어하기 위해 Benjamini–Hochberg FDR 보정을 적용했고, 참고로 Bonferroni 보정 결과도 확인했다.
- 라벨을 200회 무작위로 섞어, 단순 `p<0.05` 센서 수가 우연만으로도 어느 정도 발생하는지 노이즈 바닥을 추정했다.
- 측정 시각을 시간순 10개 구간으로 나누어 불량률의 시간 편중을 검정하고, 시간 구간 내 비교로 센서 신호를 재검증했다.

## 결과

| 지표 | 결과 |
| --- | ---: |
| 원시 `p<0.05` 센서 수 | 37 |
| 무작위 라벨의 `p<0.05` 센서 수 평균 | 23.7 |
| 무작위 라벨의 `p<0.05` 센서 수 95백분위 | 41.0 |
| BH-FDR 유의 센서 수 | 0 |
| Bonferroni 유의 센서 수 | 0 |
| 시간 보정 후 유의 센서 수 | 0 |
| 최종 검증 후보 수 | 0 |

원시 기준에서 37개가 `p<0.05`였지만, 이는 무작위 라벨에서도 95%의 경우 41개 이하가 나오는 수준이다. 관측된 37개에 대한 순열 기반 경험적 p값도 0.0945로, 우연 변동을 넘는다고 보기 어렵다. 가장 작은 원시 p값도 `sensor_298`의 0.00109였으며, 다중비교 보정 후 유의하지 않았다. 따라서 이와 같은 상위 원시 신호를 원인 후보로 해석하지 않았다.

시간 편중 검정에서 불량률의 동질성 검정 p값은 0.557이어서, 불량이 특정 시기에 유의하게 집중됐다는 증거도 없었다. 그럼에도 시간 구간 내 재검증을 수행했으며, 이를 통과한 센서는 없었다.

## 해석과 권고

현재 표본만으로 특정 공정 센서가 불량의 원인이라고 지목할 근거는 없다. 이후에는 (1) 새 기간 또는 별도 생산 로트의 데이터로 동일 분석을 재현하고, (2) 설비 상태·레시피 변경·자재 로트·장비 식별자 같은 메타데이터를 결합하며, (3) 후보가 재현될 경우 해당 공정 조건을 통제한 확인 실험을 수행하는 것이 적절하다. 센서와 불량의 통계적 연관이 발견되더라도 그 자체는 인과를 뜻하지 않으므로, 설비 이력 및 확인 실험이 필요하다.
