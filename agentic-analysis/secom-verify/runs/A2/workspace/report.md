# 불량 원인 의심 센서 분석 보고서

## 결론

불량과 가장 뚜렷하고 재현성 있게 연결된 센서는 **sensor_183, sensor_590, sensor_140, sensor_327**이다. 이 네 센서는 단순 양품/불량 비교뿐 아니라 측정 시각을 보정한 뒤와 다른 후보를 동시에 고려한 모형에서도 신호가 남았다. `sensor_301`, `sensor_292`, `sensor_103`, `sensor_008`은 효과 크기가 더 작지만 독립적인 보조 원인 후보로 관리할 만하다.

이는 관측 데이터에서의 **원인 의심도**이며 물리적 인과가 확정된 것은 아니다. 해당 공정 단계의 설비 로그·레시피 변경·측정기 교정 이력과 함께 확인하고, 다음 생산 로트에서 의도적으로 관리 범위를 좁혀 재검증하는 것이 필요하다.

## 데이터 점검

| 항목 | 결과 |
| --- | ---: |
| 웨이퍼 수 | 1,567 |
| 양품 / 불량 | 1,463 / 104 (불량률 6.64%) |
| 센서 수 | 590 |
| 상수 센서 | 116개 (분석 제외) |
| 전체 결측 비율 | 4.54% |
| 측정 기간 | 2008-07-19 ~ 2008-10-17 |

결측치는 분포 비교에서는 해당 센서의 관측값만 사용했고, AUC 및 모형에서는 학습 데이터의 중앙값으로 보정했다. 불량률은 시간대별로 1.3%~15.3%로 변동했으므로, 시간에 따른 공정 변화가 센서 효과처럼 보이는 문제를 별도로 점검했다.

## 분석 방법

1. 상수 센서를 제외한 센서마다 양품과 불량의 분포를 Mann–Whitney U 검정으로 비교하고, 474개 유효 검정에 Benjamini–Hochberg FDR 보정을 적용했다. 단변량 판별력은 결측 중앙값 보정 후 ROC-AUC로 계산했다.
2. 시간 교란을 줄이기 위해 timestamp 순서대로 같은 크기의 10개 구간으로 나눴다. 각 센서에 대해 `불량 ~ 표준화 센서값 + 시간구간` 로지스틱 회귀를 적합해 시간 보정 오즈비(OR)를 산출했다.
3. 1차 FDR 통과 센서 중 결측이 과도하지 않은 17개를 대상으로, 시간 구간 평균을 제거한 뒤 L1 로지스틱 회귀를 300회 층화 부트스트랩했다. 선택 빈도로 신호의 안정성을 확인했다.
4. 최종 8개 후보와 시간 구간을 동시에 넣은 회귀(완전 관측 1,525개)에서도 각 후보의 조건부 유의성을 확인했다.

`sensor_110`, `sensor_257` 등 일부 1차 후보는 결측이 많고 시간 구간 보정 후 유의성이 사라져 최종 후보에서 제외했다. `sensor_239`는 1차·시간 보정 비교에서는 유의했지만 `sensor_590`과 스피어만 상관 0.626이고, 둘을 함께 넣으면 sensor_239의 조건부 p값이 0.417이어서 독립 원인 후보가 아니라 sensor_590의 중복/동행 지표로 판단했다.

## 권고 조치

1. 우선 `sensor_183`, `sensor_590`, `sensor_140`, `sensor_327`의 해당 공정 단계에서 불량 웨이퍼 직전/직후의 장비 상태, 레시피, 유지보수 및 측정기 교정 기록을 대조한다.
2. 운영 알람은 불량 AUC가 가장 높은 `sensor_183`과 `sensor_590`부터 별도 관리 한계 후보를 만들고, 다음 로트에서 불량 검출 민감도와 오경보율을 검증한다. 이 데이터만으로 임계값을 확정하면 과적합 위험이 있다.
3. `sensor_239`는 sensor_590과 함께 대시보드에는 표시하되, 독립적인 원인으로 이중 계상하지 않는다.
