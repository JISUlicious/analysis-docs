# 반도체 공정 센서 불량 연관 스크리닝 보고서

## 결론

이번 데이터에서는 불량의 원인으로 보고할 만한 센서 연관 후보를 찾지 못했다. 590개 센서를 동시에 비교할 때 생기는 우연 발견을 보정하고, 측정 시각을 고려한 뒤에도 남는 센서가 0개였다. 따라서 개별 원인 센서를 지목하지 않는다.

이는 관측 데이터에서 통계적으로 검증된 연관이 없다는 뜻이며, 특정 센서가 물리적으로 원인이 아님을 증명하는 결과는 아니다. 설비 이력·자재 로트·레시피 변경 이력과 대조하거나 추가 확인 실험으로 검증하는 것이 필요하다.

## 데이터 및 전처리 현황

| 항목 | 값 |
| --- | ---: |
| 웨이퍼 수 | 1,567 |
| 센서 수 | 590 |
| 양품 / 불량 | 1,463 / 104 |
| 불량률 | 6.64% |
| 측정 시각 범위 | 2008-07-19 11:55 ~ 2008-10-17 06:07 |
| 상수 센서 | 116 |
| 사실상 상수여서 제외한 센서 | 6 |
| 결측률 50% 초과 센서 | 28 |
| 실제 검정 대상 센서 | 468 |

## 분석 방법

- 각 센서에서 양품과 불량의 분포 차이를 양측 Mann–Whitney U 검정으로 스크리닝했다.
- 468개 동시 검정에는 Benjamini–Hochberg(BH) FDR 보정을 적용했다.
- 라벨을 200회 무작위로 섞어, 우연만으로 나오는 유의 센서 수(노이즈 바닥)를 추정했다.
- 시간 흐름에 따른 교란을 줄이기 위해 측정 시각을 10개 구간으로 나누어 시간 보정 검정을 추가했다.

## 결과와 해석

| 지표 | 결과 |
| --- | ---: |
| 보정 전 p<0.05 센서 수 | 37 |
| 라벨 셔플 시 p<0.05 센서 수 평균 / 95백분위 | 23.7 / 41.0 |
| BH-FDR 유의 센서 수 | 0 |
| 시간 보정 후 BH-FDR 유의 센서 수 | 0 |
| 최종 검증 연관 후보 | 0 |
| 불량률의 시간 구간별 동일성 검정 p값 | 0.557 |

보정 전에는 37개가 p<0.05였지만, 이는 라벨을 무작위로 섞었을 때의 95백분위(41개)보다도 작다. 관측된 보정 전 발견 수는 우연 수준과 구별되지 않았고(셔플 기반 경험적 p=0.0945), BH-FDR 보정 후 남은 센서도 없었다. 또한 불량률이 시간 구간별로 뚜렷하게 달라진다는 증거도 없었다(p=0.557).

참고로 보정 전 가장 작은 p값은 `sensor_298`의 0.00109였으나, 다중비교 및 시간 보정 기준을 통과하지 못했으므로 원인 후보로 보고하지 않았다. 결측률이 60.6%인 `sensor_040` 등 결측이 많은 센서 역시 단순 순위의 근거로 해석하지 않았다.

## 권고 사항

불량이 발생한 웨이퍼의 설비·챔버·레시피·자재 로트·작업 이력 등 현재 데이터에 없는 요인을 함께 연결해 재분석하고, 의심 조건을 통제한 확인 실험을 수행한다. 이후 동일한 다중비교 및 시간 보정 기준으로 재검증한다.
